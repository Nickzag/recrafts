## Source Summary

Fresh desktop/mobile Evidence was captured from one editorial case-study shell and one product-brand site. The shell, brand system, platform UI, case-study presentation and content examples are classified separately. Exact source values and signature combinations remain in provenance files and are not portable requirements.

## Core Grammar

`sparse explanation → dense evidence → semantic data attachment → measured relationship → one visual protagonist → explicit proof`

The portable Core adds flat hierarchy, a limited signal budget, evidence before decoration and medium-aware narrative sequencing. It does not require any particular green, source font, cut corner, viewport rail, contour object, transaction chip or centered full-height Hero.

## Theme selected for previews

Mineral Ledger uses a transformed mineral surface, copper signal, offset frame, real operational imagery and an asymmetric narrative/proof topology.

## Other valid themes

- Cobalt Dispatch: non-green cobalt family, coral signal, stepped rule and right evidence column.
- Burgundy Field: burgundy/aqua family, continuous rounded field and place-led topology without cut corners.

## Source-locked observations not promoted

Exact source colors, observed source font names, cut/notched geometry, bilateral viewport rails, contour object, transaction chip, centered title/object/CTA topology and continuous marquee timing.

## Semantic Tokens

Machine-readable roles cover color, typography, spacing, grid, boundary, corner, border, shadow, motion, focus, image treatment, icon geometry, z-index and content density. Unsupported shadow behavior remains candidate rather than portable.

## Core Components

Five Core contracts are fully specified and previewed: Proof Canvas, Evidence Callout, Measured Boundary, Signal Action and Narrative Step. Source Contour Object and Continuous Marquee are rejected; Transaction Chip remains candidate because only its semantic-attachment mechanism is portable.

## Templates

Two distinct Web structures, an evidence-field Poster, an eight-page Carousel and an eight-slide projection sequence are machine-readable. Contact sheets supplement individual pages and never replace them.

## Accessibility and implementation

The preview implements landmarks, native controls, explicit figure semantics, visible focus, 44px touch targets, tested contrast pairs and CSS reduced-motion behavior. Responsive previews cover 320, 390, 768, 1024 and 1440 widths. Full screen-reader, production performance, real-device interaction and licensed production-font decisions remain production gates.
