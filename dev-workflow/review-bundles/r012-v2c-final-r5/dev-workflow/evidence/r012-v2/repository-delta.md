# R-012 v2 Repository Delta

## Existing reusable capabilities

- Envelope operation dispatch and strict operation Schemas.
- JSON Schema validator and path safety.
- Evidence, Claim, Conflict and immutable Package lineage primitives.
- Owner decision import, correction, acceptance and rollback gates.
- Browser capture, preview rendering and preview accessibility checks.
- R-011R-A Region, Measurement, State and Source-observed Token evidence compiler.

## Missing capabilities

- `recrafts.design/v1` Markdown schema and Parser.
- Public `@recrafts/design` Parser/Compiler/Compatibility package.
- Canonical Internal Design IR.
- Single-source Preview Compiler with hash freshness.
- Evidence/Candidate/Decision/Design Release identities.
- Design Release immutability and SemVer governance.
- Candidate isolation and semantic comparison.
- Separate Source Fidelity and Design Coherence gates.
- Blind qualification protocol with harness/real-agent state separation.
- Design-system consumer version lock and compatibility checker.

## Explicit non-reuse

- R-007 multi-file Package format is not the public Design System format.
- R-011R-B uncommitted implementation is not imported.
- Existing previews are not treated as Source Fidelity evidence.
- Historical K3/Grok/R-011 answers are not production dependencies.
