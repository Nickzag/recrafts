# R-013 Failure Patterns

- Partial-source start: extraction begins before every source is reviewed.
- Prior substitution: missing observations are silently filled with generic SaaS conventions.
- Authority inversion: lower-tier marketing or semantic evidence overrides primary product UI truth.
- Content contamination: user or feature content colors become system chrome tokens.
- False precision: inferred or implementation-candidate values are presented as exact observations.
- False maturity: a named component with tokens is declared downstream-ready without anatomy, states, constraints or accessibility.
- Schematic proof: Preview lists rules but does not render product-relevant composition and stress/state cases.
- Gate substitution: a coherent Preview is treated as proof of source fidelity.
- Candidate voting: scores, averaging or majority selection replace evidence-grounded rule comparison.
- Downstream invention: missing semantics are left for a consumer to redesign silently.
