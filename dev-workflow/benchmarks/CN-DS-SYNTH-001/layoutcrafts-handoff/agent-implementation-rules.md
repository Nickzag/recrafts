# Layoutcrafts Agent Implementation Rules

1. Consume `design.md` as the only public authoring source; compiled JSON is derived evidence.
2. Select a governed composition before choosing components.
3. Keep Canvas/work content visually primary and application chrome low-chroma.
4. Preserve Insert, Format, Style and Info as separate Inspector modes.
5. Treat card, dense and list as projections of the same Document object.
6. Use the accent only for interaction state; sidebar selection remains neutral.
7. Keep destructive action semantic and scoped; do not reuse decorative red.
8. Keep document imagery, gallery art, Imagine gradients and pricing art out of application tokens.
9. Emit `BLOCK`, `DEGRADED` or `UNKNOWN` for unsupported semantics.
10. Do not start migration until Mainline records Owner acceptance and implementation authorization.
