# Static Coffee Capture Policy

Source: `https://www.behance.net/gallery/251828539/Static-Coffee-Brand-Identity`

Capture is limited to public, unauthenticated case-study content. It must not bypass authentication or anti-bot controls, retain account cookies, capture private recommendations, or redistribute the complete third-party project through this repository.

The qualified local pack is `static-coffee-source-pack-v1`, currently generated under `.local-benchmark-sources/static-coffee-v1-isolated-v3/`. It contains 20 isolated static project modules selected from the project's public `project_modules` assets. Page screenshots are retained only as capture diagnostics and are not analysis sources. Four animated modules were not captured, so `capture_status` is `partial`; missing sections must not be fabricated.

The repository stores only metadata and SHA-256 hashes. Reviewers must obtain or generate the local Source Pack, verify `checksums.sha256`, and view it beside generated Artifacts. Promotion to `golden` requires a stable, reviewable Source Pack and an explicit redistribution-boundary confirmation.
