# Static Coffee L2 Brand Corpus

Static Coffee is the first candidate Corpus for Recrafts' L2 Brand benchmark. It evaluates whether an installed Recrafts package and a vision-capable Host can build an evidence-bounded brand-system package from a public multi-image case study.

The Corpus records investigation categories and auditable mechanisms, not the expected design answer. It remains `candidate` while the local Source Pack is partial and until human scoring, project-owner review, normal Recrafts correction/acceptance and an immutable baseline snapshot are complete.

Third-party images remain under `.local-benchmark-sources/` and are excluded from Git. This directory commits only source identity, hashes, dimensions, classifications and review contracts.
